# Crash matrix

| Failure point                          | Persisted state            | Expected recovery          | Duplicate delivery | Handler repeat | Business effect invariant         | Coverage                                                                                                   |
| -------------------------------------- | -------------------------- | -------------------------- | ------------------ | -------------- | --------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Before enqueue commit                  | No job                     | Client retries             | No                 | No             | No effect                         | No dedicated failure-injection test                                                                        |
| After enqueue commit, before publish   | Pending outbox             | Publisher retries          | No expected        | No             | No effect yet                     | Outbox publication integration path; broker-outage test is not included                                    |
| After NATS publish, before outbox mark | Pending/leased outbox      | Publish again              | Yes                | Possible       | Unique fulfillment                | No dedicated crash-window test                                                                             |
| After claim, before handler finish     | Running lease and attempt  | Scheduler expires lease    | Possible           | Yes            | Stale token cannot finalize       | Stale-fence integration test; container SIGKILL demo is available but not covered by the integration suite |
| During final transaction               | Transaction rolls back     | Redelivery/recovery        | Possible           | Yes            | Effect and success both roll back | Transactional implementation; rollback integration test is not included                                    |
| After final commit, before ack         | Succeeded plus fulfillment | Redelivery is acknowledged | Yes                | Claim rejected | One fulfillment per order         | Duplicate-dispatch integration test; no explicit ack-loss test                                             |
